## 4. Interpretation

The server verified the token's HMAC signature, found it valid, and
returned the profile belonging to the userId inside the token. No
password, OTP, or second factor was ever involved. Because the same
secret signs user, admin, and professional tokens, and because the
middleware does not check the token's type or audience, the same
technique can be used to mint admin tokens, which combined with
Finding 1 gives full control of the system.
